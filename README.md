# ✈️ 친구들과 함께 떠나는 여행 아키텍트 (Agentic Travel Architect)
> **Google DeepMind AI Hackathon Project** • *Interactive Collaborative Travel Workspace*

Gemini 3.8 & 4 Argon의 **정밀 지리·예산 심층 추론(Deep Reasoning)**과 **Human-in-the-Loop(HITL) 실시간 재검증**을 결합하여, 친구들과 함께 계획하고 원클릭으로 예약할 수 있는 인터랙티브 여행 청사진 플랫폼입니다.

---

## 🌟 핵심 특징 (Key Highlights)

1. **🔗 원클릭 예약 & 실시간 길찾기 링크 자동 연동**
   - 생성되는 모든 일정의 방문지, 식당, 숙소, 액티비티마다 바로 접속 가능한 **[📍 구글 지도 길찾기]**, **[🍽️ 맛집 예약/리뷰]**, **[🎟️ 클룩 티켓]**, **[🏨 아고다 숙소]** 마크다운 링크가 기본 탑재됩니다.
   - 상단에 **원클릭 예약 센터**(스카이스캐너, 아고다, 에어비앤비, 클룩, 구글맵)가 상시 배치되어 친구들과 가격을 비교하고 즉시 예약할 수 있습니다.

2. **📄 정밀 한국어 PDF 리포트 다운로드**
   - 마크다운(.md) 저장뿐만 아니라, **맑은 고딕(Malgun Gothic) 폰트가 적용된 고해상도 PDF 리포트**를 원클릭으로 다운로드하여 비행기나 여행지에서 오프라인으로 열어볼 수 있습니다.

3. **👥 친구들과 함께 보는 인터랙티브 협업 스페이스 (Tab 3)**
   - **체크리스트**: 여권, eSIM, 트래블월렛, 멀티어댑터, 상비약 등 필수 짐 싸기 인터랙티브 체크박스.
   - **취향 투표 (Quick Poll)**: 친구들과 식사 스타일(로컬 vs 미슐랭) 및 페이스(늦잠 힐링 vs 명소 정복)를 투표하고 원클릭으로 일정에 반영.
   - **단톡방 공유 카드**: 카카오톡/메신저에 복사해 보낼 수 있는 예쁜 일정 요약 텍스트 생성기.

4. **✨ 눈이 편안한 고대비 모던 트래블 워크스페이스 디자인**
   - 어두운 배경의 답답함을 벗어나, **Wanderlog/Airbnb 스타일의 화사하고 깨끗한 화이트 & 스카이블루 고대비 테마**를 적용하여 어떤 화면에서도 가독성이 뛰어납니다.

5. **⚡ 100% 무중단 안정성 (기본 모델: `gemini-3.8-flash` & 자율 Fallback)**
   - 무료 API 키에서도 쿼터 초과(429)나 가용성 오류(404) 없이 즉각 작동하며, 고사양 모델 선택 시에도 스마트 Fallback이 보호합니다.

## 🚀 빠른 시작 가이드 (Quick Start)

### 1. 패키지 설치
```bash
pip install -r requirements.txt
```

### 2. Gemini API Key 설정 (선택 사항)
```powershell
# Windows PowerShell
$env:GEMINI_API_KEY="your-gemini-api-key"
```
*(UI 입력창에서도 직접 입력할 수 있습니다.)*

### 3. 애플리케이션 실행
```bash
python app.py
```
브라우저에서 `http://localhost:7860`으로 접속합니다.
